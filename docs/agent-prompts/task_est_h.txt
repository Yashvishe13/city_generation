Create scripts/estimators.py (Python 3, standard library only). Do not modify any other file.

Scope for now: ONE estimator - building height, for footprints that state neither `height`
nor `building:levels`.

Hard requirement: it must fit everything from the area's own data. No constant tuned to a
particular city. Right now scripts/convert_to_ue.py hardcodes NYC values (LANE_M = 3.25
"NYC DOT", class widths justified by "Park Ave / 42nd St"); that is the anti-pattern we
are replacing. If an area has no signal to fit, say so and degrade explicitly.

Include a validation mode: hide the known heights, predict them, and report median and
mean absolute error, alongside the error of a trivial baseline (the area's global median
height), so we can see whether the estimator earns its place.

Run validation on data/raw/nyc_midtown.geojson (heights well tagged) and
data/raw/paris_marais.geojson (almost no height tags, floor counts instead), and report
the numbers for both. Say plainly which area it works for and which it does not.
